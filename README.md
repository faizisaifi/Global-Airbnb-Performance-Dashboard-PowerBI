# Global Airbnb Performance Dashboard | Power BI

## Project Overview

An interactive Power BI dashboard analyzing Airbnb performance across major cities.

The dashboard focuses on market share, listing distribution, average prices, city-level performance, and customer ratings.

## Dashboard Pages

### 1. KPI & Market Analysis
- Key performance indicators
- Market share by city
- Listing distribution
- Average prices
- City-level performance

### 2. Rating Analysis
- Overall customer ratings
- Accuracy
- Cleanliness
- Communication
- Location
- Value

### 3. City & Performance Analysis
- City-level comparisons
- Listing performance
- Price analysis
- Overall performance comparison

## Tools & Skills

- Microsoft Power BI
- Data Analysis
- Data Visualization
- Dashboard Development
- Market Analysis
- Rating Analysis

## Project Objective

The objective of this project is to analyze Airbnb performance across different cities and present the findings through an interactive business intelligence dashboard.
